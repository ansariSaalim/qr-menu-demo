# MenuMitra demo

Clickable prototype of a QR menu and table-ordering platform for restaurants.

- **Diner phone:** scan a table QR, browse the menu, choose portions and add-ons, order, track status, pay by UPI or at the counter.
- **Owner dashboard:** live order board with sound alert, kitchen tickets (KOT), menu and stock, table QR codes, reports, plan and settings.
- **Restaurant sign-up, plans (Freemium / Basic / Advanced / Premium) and a platform admin view.**
- A guided tour walks through the whole flow in 13 steps.

Everything runs in the browser from one `index.html` with sample data. Nothing is saved or sent anywhere.
